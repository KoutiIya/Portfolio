# Website files

This directory contains the buildless portfolio website. For preview commands, checks, Git workflow, and future Cloudflare configuration, see the repository's root README.

The Podoscope hero uses compressed WebP sequences from `images/podoscope/hero/`. Original PNG masters in the local `podo port` folder are intentionally excluded from Git.

The website requests Barlow from Google Fonts. Existing Elza files are retained but unused. There is no deployment configured by this repository setup.
